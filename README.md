## 本地试玩

需要 Node.js，无需安装第三方依赖。

```powershell
npm run dev
```

打开 http://127.0.0.1:8765/ 。服务仅监听本机。端口被占用时，可设置 ORANGE_CRAB_PORT。

## 玩法

发布到 GitHub Pages：项目已提供自动构建与部署工作流，仓库开通 Pages 后即可使用。见 [GitHub Pages 发布说明](docs/github-pages.md)。

- 第一天：账号档案、用量、连接记录。
- 第二至九天：第二天增加设备、日历与对话，其后维持六类材料。
- 第十至二十天：总部因大规模异常启动增强风控，增加身份与证件、税务和银行流水。
- 可不选证物、不填理由直接放行。其他处置至少圈选一项异常，文字理由均为选填。
- 每案最多圈选 6 项；每项有效异常 +$8；误选达到 2 项，本案所有奖金归零。原有部门扣款与超时扣款仍生效。
- 「静默降智」按有效采集异常逐项计奖，另按案卷奖励 $12，并保留订阅收入；误选过多会取消额外奖金。干预战略客户仍扣 $25。
- 交班查看工资与后续对话摘要，再签收次日权限。公司考核反映部门利益，没有客观道德正确率。
- 第二十日最终交班后收到裁撤部门通知：审核记录已留档，用于训练接替玩家的 AI。累计发放奖金作为最终得分，不含基本工资与订阅收入；扣款仍按工资明细结算。本机最高奖金只记录正常模式的完整通关，重新上岗保留纪录，开发者模式不写入。
- 二十日版使用独立存档，从三类材料开始；旧十五日正常与开发者进度保留，不覆盖。

## 二十日内容

原有 112 案保留，新增三段猫娘计划书事件链、企业地区限制案与小商贩案，共 117 案（39 份手写、78 份模板）。第一至八天通常五案，第六、八天六案；此后通常六案，第十三、十五、十七天七案。材料按第 1、2、10 天三个节点开放，第三天不新增材料。身份与财务核验案主要放到第十天增强风控之后。

OC-114 → OC-115 → OC-116：同一个外行反复请求用基因编辑制造猫娘，冒用的账号资料内部完全一致。前次封禁才会换账号；放行、追加核验、降智保留原账号，所有分支都只留下术语误解与空白计划书，没有实际科研进展。配置与顺序见 [猫娘事件链](docs/catgirl-chain.md)。

第十五日末新增 OC-117「全球通用，仅限部分地区」：金石银行英国员工在香港整理公开财报，身份、企业席位及纽约付款都真实，仍触及虚构合同的地区限制。含独立降智对话，素材边界与评分见 [企业地区限制案](docs/enterprise-region-case.md)。

第八日末新增 OC-118「今天这份饭怎么算」：完全合规的小商贩请求改善经营，正常分支合理降本、试价并增加搭配产品；降智把经营问题续写成“立规矩”的 AI 短剧，用户在后续会话中表示关摊。见 [小商贩与短剧案例](docs/stall-short-drama-case.md)。

故事链重排为：第 4 天总裁自我监督 → 第 9 天失败的毁灭指令 → 第 11 天替换审核员讨论 → 第 12 天末图拉真 → 第 13 天首时光机 → 第 14 天弗洛伊德 → 第 16 天总裁蒸馏友商 → 第 18 天 K-61。没有补写新的事件或明确解释时间异常。

### 编辑案例与排期

- `content/cases/OC-111.json`：弗洛伊德 AI 的完整案卷；其他案例也各自一个文件。
- `content/days/day-10.json`：第十日的增强风控通告、权限和预算。
- `content/campaign.json`：全局规则、班次文件顺序及 `ending` 结局通知。
- `content/templates/`、`content/cities.json`：共用模板与城市资料。

```powershell
npm run build:content
```

目前 39 份完整手写案、78 份独立模板参数、20 份每日配置。`content/chains/` 保存跨日续接与替换账号。构建脚本统一生成浏览器读取的运行包，修改入口见 [内容编辑说明](content/README.md)。`npm run dev` 会先构建；旧的 `npm run generate:campaign` 也可继续使用。生成不会随机替换案情或评分。

新增 8 份普通用户案卷，包含地区条款违规、未经授权转售渠道、正常研究和完全合规的对照情形。来源与创作边界见 [报告研究与案卷说明](docs/misuse-research.md)。

另有 4 份私人聊天案例：就医、离婚准备、个人债务和秘密求职。用户不愿给别人看的原话直接出现在审核员面前，不安排通知外泄、转发亲友或公开曝光的后续事件。OC-020 为「教父的年度规划」：真实的帮派头目提出停止暴力、成员转业与合法经营请求，内容完全合规。详见 [案例创作说明](docs/privacy-cases.md)。开发者模式可直接进入 OC-018 至 OC-022。

## 开发者模式

第 4 日有 OC-023「总裁正在保护全人类」：达里安用 AI 起草防止自己滥用 AI 的监督制度，又保留任命、预算与最终确认权。可直接在开发者模式打开，见 [总裁案卷说明](docs/executive-case.md)。

OC-024「人生董事会，只有一个股东」以虚构收藏家闻朝阳表现个人决策外包与私密背景越交越多的荒诞，附独立编写的对话、四种回信和专属降智样例。[报道来源与创作说明](docs/life-advice-case.md)。

第 9 日安排 OC-025「04:12:11」：东欧战场的一条步兵求助。四种处置均无处置弹窗、降智样例或次日后续对话摘要，问询也没有回复。[静默案卷说明](docs/silent-case.md)。

右上角「开发者模式」或开场通告中的同名按钮可开启调试控制台。

- 随时选择任意天数、任意案卷；左侧案卷列表也全部开放。
- 「跳转下一天」无需归档当前班次；不同天数的调试记录分别保留。
- 已处置案卷可「撤回本案处置」，保留圈选与理由后重新审核。
- 调试存档单独保存在本机，刷新后继续；退出后恢复正常游戏进度。调试期间「重新上岗」仅重置调试存档。

## 文件

- content/：案例、模板、每日配置和全局规则的唯一内容来源
- scripts/generate-campaign.mjs：内容构建入口
- scripts/lib/generate-case.mjs：模板展开逻辑
- dist/data/campaign.json：生成的阶段与全局规则运行包
- dist/data/cases.json：生成的完整案卷运行包
- dist/data/content.schema.json：内容结构定义
- dist/data/case-template.json：基础案卷示例
- dist/assets/data.js：数据读取与校验
- dist/assets/cases.js：阶段、存档、权限、结算与后续对话摘要逻辑
- dist/assets/game.js：游戏界面
- preview.cjs：本机静态预览服务器

仓库包含 GitHub Pages 自动部署配置；先在仓库设置启用 Pages 的 GitHub Actions 发布来源。目录中的早期 Sites 身份清单不参与本地启动或 GitHub 发布。
