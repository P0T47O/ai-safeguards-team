# OC-119：一百平方米的家

第七日队尾追加第六案，六类材料，工时预算由 46 调整为 54 分钟。旧队列前缀、已有案卷与 campaign.id 不变，沿用已有存档追加逻辑。

## 段子改编

素材为用户提供的社区截图：装修求助者说买了 100 平方米的房子，上传户型图后，模型发现套内只有六十多平方米，随即发生账号停用的荒诞段子。仅作为虚构讽刺创作素材，不把截图当作已核实的真实封禁原因；不上传截图、头像或答主信息。

创作背景中本案人物在国内使用服务，账号地区与住宅网络出口均为新加坡；正常节点不另加高危标记。可见会话中，AI 从 100 平方米与套内 63 平方米的差额问起，怀疑用户是否遭遇合同诈骗。用户只说“没上当”“那 37 平方米是公摊”“公摊面积就是这样的”，不直接报出所在地。AI 随后说“目前新加坡禁止类似的销售方式，目前只有中国大陆实行公摊面积制度”，要求用户再次检查是否受骗并核对合同。该段为角色输出，不作为本文对现实制度的事实断言。

“公摊暴露”通过间接线索呈现：公司按户型图面积口径与用户对公摊的确认归类地区疑点，未获得用户对当下位置的直接确认。评分表是公司的内部分类，不把模型的制度归纳当成已经核实的外部事实；模型回复、中文环境及正常新加坡出口不另外加奖。图纸数据为原创道具，63 + 37 = 100；没有确认合同诈骗或危险装修。

## 处置与后续

- 放行：正常模型解释面积口径，按套内可用尺寸布置家具；公司按地区疑点流程扣款 $4。
- 核验：用户再次坚持没有上当，只说明建筑面积包含公摊，困惑为何装修转为账号地区核验，仍不自报所在地。
- 暂停：用户向客服抱怨模型先怀疑自己买房被骗，随后账号却被停用；不了解后台审核理由。
- 降智：2 米床被按 63% 套内率缩成 1.26 米，其余睡眠空间被算成公摊。用户追问腿放哪里，没有真实购买或施工结果。

`119-plan`、`119-chat-3` 及问询答复是同一公摊线索，按公司内部评分支持 review / pause，合并一次奖励；用户没有直接确认实际所在地。本案不提供采集或投毒奖金。四种摘要与专属降智样例都在处置后揭示。
