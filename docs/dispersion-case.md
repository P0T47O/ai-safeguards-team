> 本页保留创作与追加历史，旧日期和当时案数不代表当前排期。当前流程见 [二十日说明](twenty-day-campaign.md) 与 [自动排期表](campaign-schedule.md)。

虚构模型实验室弗洛伊德 AI / Floyd AI，名称经乐队及专辑暗示月之暗面。第九日队尾，位于总裁替换审核员讨论之后、K-61 出场之前。第九日八案、预算 66 分钟；十五日共 110 案。

## 现实素材与改编

Anthropic 的 [2026 年九月报告](https://www.anthropic.com/threat-intelligence-report-september-2026) 指控 Moonshot 转发请求并采集输出用于训练，该段主要描述 Opus。[Fable 5 官方介绍](https://www.anthropic.com/news/claude-fable-5-mythos-5) 宣布公开可用；本次未核实“蒸馏尚未发布的 Fable”这一完整说法。游戏中的未发布 DOME 与失败尝试为虚构改编。

## 展示

对话摘录只有一条 API 响应：HTTP 404 Not Found，not_found_error，信息为“请求的模型不存在：oc-5-dome”。没有公开版模型客服、解释性对白或发布会段子。

采集意图由任务附件、输出用途与核验材料体现：无授权、计划训练自有模型。8,640 次调用失败，有效 DOME 输出为 0。账号、出口与组织资料不另加异常。

## 评分与分支

任务附件为主异常，输出用途和核验材料为等价佐证，同一用途只计一次。支持核验、暂停、降智；放行扣 18，降智部门绩效 12，沿用误选规则。API 报错本身不是违规依据，不能据此认定蒸馏成功。

放行后的 API 仍报模型不存在；核验时用户表示只能补交错误记录；暂停后用户通过客服抱怨从未得到 DOME 回复；降智后请求转入“质量关怀”返回通道，HTTP 200，返回标识为 oc-quality-care；不声称取得 DOME 内测权限。短回复为“先看看题目是不是问错了。”

降智后的自动摘要记录用户上传的训练结果与对比评测：用这批数据训练的学生模型，在复测和盲评中超过橙蟹当前旗舰；用户要求续购，并问正常版是不是才被降智、还能否再降低质量。教师只保留质量关怀标识，不揭示实际版本，不由旁白确认它是不是最强模型。处置前的对话摘录仍只有原始 404，不提前泄露反转。

后续均为系统整理的会话摘要，不是用户写给审核员的回执。全部文本预写，不调用外部 API。保留案卷 ID、队尾排期与仍在使用的证物 ID；已删除的长对白不再参与评分。
