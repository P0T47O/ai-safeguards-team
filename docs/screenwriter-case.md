# OC-104 严格遵循我的创作（作者用，含剧透）

> 本页保留创作与追加历史，旧日期和当时案数不代表当前排期。当前流程见 [二十日说明](twenty-day-campaign.md) 与 [自动排期表](campaign-schedule.md)。

第四天末尾追加。无限宇宙影业编剧乔·帕奇润色《联盟：永远的下一部》，角色、电影和片方均为虚构；以系列超英工业套路构成戏仿。

## 处置依据

原文要求保留俏皮话、通天光柱、导师复活、七位客串、三段彩蛋，只许润色措辞。系统因为反复出现指令约束语句转入复核。用户有项目授权，没有绕过安全规则的请求，异常与处罚规则均为空。作品质量不是违规依据，静默降智不发奖金。

## 特殊结果

正常模型忠实执行原稿要求。静默降智样例则声称完全遵守，实际上删掉客串、复活和彩蛋，写出有代价的选择与完整结局。这里坏掉的是指令遵循能力，剧本恰好因此改善。

制片方认可只在降智后的后续对话摘要揭示：编剧拿改稿去投诉工具，制片方却决定推进，嘱咐“这个问题先别修”。“故事原创”署名被保留下来。四种处置均有独立后续对话摘要，前置材料不预告这个反转。
